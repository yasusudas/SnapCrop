# SnapCrop

ブラウザ上で画像を読み込み、画像内でクリックした色を基準に上下左右の各辺から切り抜けるシンプルなツールです。

## できること

- `jpg` `png` `tif` `tiff` を読み込み
- 画像をクリックしてスポイトのように色を選択
- `Top / Bottom / Left / Right` ごとに切り抜き有効化
- 選択した辺から最初に見つかった対象色の **1px内側** で切り抜き
- 許容差スライダーで JPG の微妙な色ズレにも対応
- 切り抜き結果を PNG で保存

## 使い方

1. `index.html` をブラウザで開きます。
2. 画像を読み込みます。
3. 元画像をクリックして対象色を選択します。
4. 切り抜きたい辺だけをオンにします。
5. 必要なら一致許容差を調整して `切り抜きを実行` を押します。
6. 結果を確認して `PNGで保存` します。

## 補足

- `Bottom` をオンにした場合は、画像の下端側から対象色を探索して切り抜きます。
- `tif` の読み込みには `UTIF.js` を利用しています。
